# Positioning

Checked 2026-11-01 against Illia's ideas post (x.com/ilblackdragon/status/2106269343881519444), Gloam's post (x.com/gloamtrade/status/2116520235897434506) and the track prompts.

Darkroom is not on Illia's list. It is close to these items:

- Private OTC market: "no way to find counter party". Darkroom has discovery and fill for information, not tokens.
- Selling viewing keys: a key is a secret that loses value once seen. Darkroom can sell one.
- AI benchmarking with private test sets: same primitive, an agent reads private data in an enclave and only a result leaves.
- Private code review: the same room pattern.

The framing that follows: a general way to sell anything that loses value once seen. Exploits are the demo.

The privacy track prompt asks for NEAR AI Cloud, attestation with a fresh nonce, a Verified panel, nothing kept server side, and fictional sample data. Darkroom covers all but NEAR AI Cloud and the panel, which belongs to the UI stage.

Update: Gloam is now built in, as the private payment path. See gloam-design.md.

Gloam offers private balances and payments on Base, Ethereum, Tempo and Robinhood Chain, not NEAR, reachable through Intents, which is mainnet only. Its docs were not read. It could hide who paid whom, but it costs real funds, and it would dilute a NEAR-centred entry. Not planned for the core.
